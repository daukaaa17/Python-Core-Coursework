# Python Core Coursework

## Overview

This repository contains Python programming exercises and practical assignments completed as part of the EPAM Data Software Engineering Trainee programme (Oct 2024 – Feb 2025) coursework.

The exercises cover fundamental Python concepts, problem-solving techniques, and object-oriented programming.

## Topics Covered

- **Data Types and Structures:** Numbers, strings, lists, tuples, dictionaries and sets.
- **Functions:** Function definitions, arguments, recursion and decorators.
- **Object-Oriented Programming:** Classes, objects, inheritance, methods and special (magic) methods.
- **Exception Handling:** Handling runtime errors and implementing exception handling.
- **Python Core Concepts:** Variables, loops, conditions, modules and basic programming techniques.

## Technologies

- Python
- Git
- GitHub

## Repository Structure

The repository is organized into separate folders containing exercises and assignments covering different Python programming topics.

## Purpose

The main objective of this coursework was to strengthen Python programming fundamentals, improve problem-solving skills, and gain practical experience with object-oriented programming.
